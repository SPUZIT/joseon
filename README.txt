조선 한 평생 - 사이트 폴더

들어 있는 파일
  index.html   게임 전체 (파일 하나로 동작합니다)
  og.png       링크를 공유할 때 보이는 미리보기 이미지 (1200x630)
  favicon.svg  브라우저 탭 아이콘

올리기 전에 한 번만 할 일
  index.html 안의 YOUR-DOMAIN 을 실제 주소로 바꿉니다. (3군데)
  예) https://joseon.pages.dev  또는  https://내도메인.com
  메모장에서 "바꾸기"로 YOUR-DOMAIN 을 전부 바꾸면 됩니다.
  주소를 아직 모르면 먼저 올린 뒤, 생긴 주소를 넣고 다시 올립니다.

올리는 방법 (가장 쉬운 것)
  Cloudflare Pages
    1) dash.cloudflare.com 가입 -> Workers & Pages -> Create -> Pages
    2) "Direct Upload" 선택 -> 이 폴더를 통째로 끌어다 놓기
    3) 프로젝트 이름을 정하면 https://이름.pages.dev 주소가 생깁니다.

  Netlify
    1) app.netlify.com/drop 접속
    2) 이 폴더를 화면에 끌어다 놓기. 바로 주소가 생깁니다.

  GitHub Pages
    1) 새 저장소를 만들고 이 파일들을 올립니다.
    2) Settings -> Pages -> Branch: main 선택 -> 저장

내 도메인 연결
  도메인을 산 곳에서 위 서비스가 안내하는 DNS 값을 넣으면 됩니다.
  각 서비스의 Custom domain 메뉴에서 단계별로 안내합니다.

참고
  - 글꼴은 Google Fonts에서 불러오므로 인터넷이 연결된 상태에서 가장 예쁘게 보입니다.
  - 추모관 기록은 방문자 각자의 브라우저에만 저장됩니다.
